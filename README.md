# 🍕 BV Conveniência - Cardápio Digital

Este é um sistema de **Cardápio Digital Interativo** desenvolvido para otimizar o atendimento de estabelecimentos de delivery via WhatsApp. O projeto simula a experiência de um aplicativo nativo (App), oferecendo rapidez, facilidade de uso e uma interface moderna e responsiva.

---

## 🚀 Funcionalidades

- 📱 **Interface Mobile-First:** Design totalmente focado na experiência do usuário via smartphone.
- 🛒 **Carrinho Persistente:** Os itens não somem se a página for atualizada (uso de LocalStorage).
- 🍕 **Seleção Inteligente de Sabores:** Modal específico para pizzas permitindo a escolha de 1 ou 2 sabores, com cálculo automático baseado no sabor mais caro.
- 💰 **Cálculo de Preços em Tempo Real:** Soma automática de produtos e quantidades.
- 💳 **Gestão de Pagamento:** Escolha obrigatória da forma de pagamento com campo dinâmico para troco.
- 💬 **Integração com WhatsApp:** Envio de pedido formatado diretamente para o número do estabelecimento.
- 🧹 **Autolimpeza:** O carrinho é esvaziado automaticamente após o envio bem-sucedido do pedido.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web puras (Vanilla), garantindo máxima performance e leveza:

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização moderna com Flexbox e variáveis CSS.
- **JavaScript (ES6+):** Lógica do carrinho, manipulação de DOM e persistência de dados.
- **FontAwesome:** Biblioteca de ícones profissionais.
- **Google Fonts:** Tipografia limpa e legível (Segoe UI/Roboto).
